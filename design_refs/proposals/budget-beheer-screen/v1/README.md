## Concept

Minimal / rustig / taakgericht.

Doel: beheerpagina direct begrijpelijk maken door minder visuele concurrentie en een strakke volgorde.

## Layout structuur

1. **Kernsturing (bovenaan, compact)**
   - Budgetmodus + spaardoel in één samengevoegde hoofdkaart
   - Korte, niet-technische uitleg
2. **Inkomende ruimte**
   - Inkomstenbasis + preview in één kaart
   - Maandverdeling direct eronder als compacte samenvatting
3. **Categoriebeheer**
   - Korte samenvatting “waar staat je verdeling nu”
   - Daarna bestaande categorie-rijen en acties
4. **Secundair**
   - Jaarlijkse lasten in compacte kaart met `Beheer`-actie
5. **Vaste footeractie**
   - `Opslaan` als duidelijk primair slot

## Component gebruik

- Behouden:
  - bestaande mode chips, slider, choice chips, category rows, reserve-rules sheet
- Herordenen:
  - `Inkomstenbasis` + `Maandverdeling` visueel dichter bij elkaar
  - `Jaarlijkse lasten` lager in prioriteit
- Vereenvoudigen:
  - helpercopy halveren
  - dubbele uitlegregels verwijderen

## Wat is beter

- Sneller te begrijpen voor doelgroep zonder financiële voorkennis.
- Minder scroll- en leesdruk.
- Primair doel (“hoe stel ik dit goed in?”) is direct zichtbaar.
