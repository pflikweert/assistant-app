## Concept

Coachend / helder voor brede doelgroep.

Doel: instellingen blijven volledig, maar met duidelijke begeleiding: wat betekent dit en wat moet ik nu doen.

## Layout structuur

1. **Korte contextkaart**
   - “Zo stel je je maandruimte in” in 1-2 zinnen
   - directe status van huidige planning
2. **Stap 1: Kies je manier**
   - Budgetmodus + spaardoel
3. **Stap 2: Kies je inkomensbasis**
   - income chips + preview
4. **Stap 3: Verdeel over categorieën**
   - maandbudget per categorie + trend/herstelacties
5. **Optioneel beheer**
   - jaarlijkse lasten als secundaire “extra beheer” sectie
6. **Duidelijke afronding**
   - primaire `Opslaan` knop met korte bevestigende microcopy

## Component gebruik

- Behouden:
  - alle bestaande controls en bestaande sheets
- Herkaderen:
  - sectietitels in stap-vorm (1/2/3) voor begrijpelijkheid
  - technische termen reduceren in zichtbare copy
- Vereenvoudigen:
  - maximaal 1 helperzin per sectie

## Wat is beter

- Beter te begrijpen voor minder financiële gebruikers.
- Minder cognitieve belasting door stap-structuur.
- Functionaliteit blijft intact, maar voelt minder “complex formulier”.
